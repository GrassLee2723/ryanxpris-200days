RYAN × PRIS — 200 DAYS — V3

V3 keeps the V2 story and presentation, with a consistency pass focused on:

1. Direct-address grammar: Ryan speaks to Pris as “I” → “you”. Common you/your and was/were errors have been corrected.
2. Kelly clarification: the first-meeting line now says Ryan naturally stuck with Kelly because she was the only person he already knew.
3. Unified middle palette: from the Mars arc through the last Malaysia trip before New Zealand, the visual system uses one deep plum/brown background, warm ivory text, and dusty pink accents.
4. Unified typography hierarchy: DM Mono for labels, Inter for narration, Playfair Display for emotional/large statements.
5. Consistent contrast: major serif statements are ivory; emotional emphasis and quotes use the same pink accent; muted copy remains readable on the dark background.
6. Ambient scrapbook graphics now enter from the Mars era and stay within the same pink/ivory palette.
7. Johor/farewell and the New Zealand sections remain intentionally quieter and darker so the emotional shift is clear.
