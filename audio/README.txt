MUSIC FILES — V6
=================

Place these four MP3 files in this folder. The website code is already wired to them.
All four tracks are set to loop within their assigned story section. When the story crosses into the next music section, the current track is stopped and the next track is crossfaded in.

01-tong-hua.mp3
  童话 — Michael Wong (piano version)
  Used: Opening / Chapter 01

02-man-man.mp3
  慢慢 — 颜人中 (piano version)
  Used: Mars Arc / Chapters 02–06

03-love-story.mp3
  Love Story — Taylor Swift (piano version)
  Used: Genting through the chapter before the final trip to New Zealand / Chapters 07–17

04-a-thousand-years.mp3
  A Thousand Years — Christina Perri (piano version)
  Used: Final trip to New Zealand through the ending / Chapters 18–21 + final

IMPORTANT
---------
The MP3 files are intentionally not bundled. Download/obtain your chosen piano versions yourself and place them here using the exact filenames above.

LOOPING
-------
Each <audio> element has the HTML loop attribute, so the track repeats automatically while its act is active.
